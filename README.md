# CSAP
# 🛡️ CyberShield Awareness Platform (HTML, CSS, JS, React)

This is a web-based Cyber Security Awareness Platform developed in **HTML**, **CSS**, **JavaScript**, and **React** (frontend only), designed to help users learn cyber safety, read awareness articles, take interactive quizzes, and report incidents.

---

## 💡 Features

- Modern landing page with call to action and highlights
- User authentication: login/signup (Google login demo, instant login)
- Role-based access: User/Admin
    - **User** can take quiz, view articles, report incidents
    - **Admin** can manage articles/quizzes (demo role in frontend)
- Awareness Articles: Author attribution, expert tips
- Safety Tips: Passwords, emails, web, mobile
- Interactive Quiz: 10 questions, result summary, explanations for right/wrong answers
- Incident Reporting: File upload, description, submit for awareness
- Responsive UI for desktop and mobile
- All data stored in browser (LocalStorage)

---

## ⚡ Technologies Used

- **HTML5**
- **CSS3**
- **JavaScript (ES6)**
- **ReactJS** (for modular frontend)
- **LocalStorage** (for simplified DB/demo)
- Tested: Chrome, Safari, Edge, Firefox

## 🚀 Getting Started

1. **Clone the repository**
 - git clone https://github.com/Mittaldruvan/CSAP.git
 - cd CSAP
2. **Run in browser**
 - Open `index.html` in Chrome, Edge, or Safari (no server required)
 - Use site navigation to access quiz, articles, report, and tips pages
3. **Login/Signup**
 - Use any email and password for instant login in demo
 - Try Google login button for instant login example
